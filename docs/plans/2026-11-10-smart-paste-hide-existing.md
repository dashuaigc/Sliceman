# 批量粘贴隐藏原有图层

用户要求增加是否隐藏内部图层选项，默认否，并解释原位。

设计：三行选项沿用否/是按钮样式，hideExisting 为布尔值，旧设置默认 false，记住上次选择，执行中锁定。仅隐藏本次粘贴前的根层与组，保留子层状态和新增层状态。

实现顺序：补充宿主/面板回归测试并观察失败；增加 UI 配置与传参；新增层完成层级移动、居中后设置原有根层 visible=false；失败走原有不保存关闭逻辑；运行相关测试和浏览器窄面板检查；提供独立 UDT 包供 Photoshop 验证。

原位调用原生 paste inPlace:true，不增加位移缩放；居中按新增层联合边界进行整体平移。

后续确认：放置位置默认改为居中，并将居中选项前置；已有偏好保持。发布 v1.4.8，更新 README/Pages 及截图，提供 CCX 和 Setup ZIP。
