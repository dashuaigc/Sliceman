# 智能对象内部批量粘贴 Implementation Plan

**Goal:** 撤销双模式样板功能，直接将 Photoshop 已复制的单个或多个图层粘贴到选中的智能对象内部，交付独立 UDT 测试包。

**Architecture:** 单一粘贴服务通过 Photoshop 原生 paste 命令保留剪贴板图层结构；逐个打开、定位、保存并关闭插件打开的内部文档。界面只有最上方/最下方、原位/居中、执行、进度及停止，不提供样板、fx、覆盖、匹配和试用模式。

**Tech Stack:** Photoshop UXP DOM + batchPlay、HTML/CSS、Vitest、esbuild。

## 已确认行为

- 用户在 PS 中复制完整图层或组，再选目标智能对象，执行一次。
- 原位采用 PS 原位粘贴；居中把粘贴的多个根层作为整体平移，不缩放、不额外套组。
- 默认根部最上方，最下方仍在背景及其剪贴链上方；保留粘贴层顺序及剪贴关系。
- 只追加，不删除已有内容。保留图层自带效果，不单独复制或合并 fx。
- 只处理可保留图层的嵌入式 PSD/PSB 内容；其他格式、链接文件、已打开内容明确跳过。
- 同源智能对象按确定的内容身份/完整内部路径去重，不按同名推测。
- 每个对象成功后保存；失败关闭自身打开的内容且不保存。结束恢复原文档和选择。
- 停止在对象边界生效；不承诺跨文档一次撤销。处理期间不修改剪贴板。
- 保留定位格对象间距以及所有无关工作区改动。

## 执行步骤

1. 撤销旧版专用 core、host、UI、测试、打包脚本及说明；保留共享文件中的其他改动。
2. 先写宿主边界失败测试：多层原位、整体居中、根部层序、背景剪贴链、剪贴板失败、保存失败、共享去重、已打开内容、取消、恢复选择。
3. 实现 src/ps/smart-paste.js，使用注入宿主工厂测试原生操作边界。
4. 先写简单面板行为测试，再实现 src/ui/smart-paste-panel.js、替换 HTML/CSS 和 panel.js 接线。
5. 独立审查规格和实现；运行针对性和全量回归、构建和窄面板检查。
6. 新建 scripts/pack-smart-paste-test.mjs 和 docs/udt-smart-paste-test.md，生成独立 ID 的标准 ZIP，核验 manifest、资源和 bundle。

## 验证边界

自动化宿主桩可以验证调度、描述符、层序、保存/关闭和失败处理，不能代替 Photoshop 原生剪贴板多层粘贴实测。交付说明必须如实标明实际完成的验证。
