# Sliceman v1.4.6 发布计划

**Goal:** 保持现有 README 和 GitHub Pages 手册格式，更新对象间距、智能对象内部批量粘贴及最终按钮交互的文字和截图，发布 CCX 与 Windows Setup 两种安装格式。

**Architecture:** 现有工作区准备版本及图文；从 origin/main 创建隔离发布工作区，只复制本次功能、文档和已有独立安装器源码。Pages 保留现有 CSS、导航和未改动章节，替换受影响章节及截图。GitHub Release 先建立草稿、上传并核验两项附件，再公开。

**Steps:**
1. 核对远端 main、gh-pages、v1.4.5 release、安装器与历史格式。
2. manifest/package/lock/UI 版本统一为 1.4.6，更新 README 批处理和定位格章节及版本说明。
3. 用当前正式构建更新界面浏览器预览，增加红色停止、完成状态和间距示例，保持原截图尺寸及声明。
4. 执行全量插件回归、独立安装器隔离测试，构建 CCX 与 Setup ZIP，核验版本、身份、文件完整性和 ZIP 路径。
5. 检查 README 链接和 Pages 桌面/手机渲染；隔离提交后推送 main、gh-pages 及 v1.4.6 标签。
6. 上传两项附件，核验下载文件摘要、发布 Release；检查 GitHub Pages 部署结果。

用户已明确授权推送和正式发布，无需额外确认。不会覆盖其他未纳入本次发布的草稿或在真实用户插件目录执行安装测试。
