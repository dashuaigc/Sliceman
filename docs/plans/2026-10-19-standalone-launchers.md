# Sliceman 中文安装入口实施计划

## 最终交付调整

用户后续确认：发行包改名为 `Sliceman_Setup_v1.4.5.zip`；卸载不再输入数字，打开卸载页面后点击底部“确认卸载”按钮即可。按钮位于“取消”左侧。“安装完成”和“卸载完成”使用 20 号粗体显示。下方为初始设计记录，数字确认已被这一最终方案替代。

**Goal:** 独立包提供带图标的安装/卸载 EXE，PS 打开时等待退出，所有用户提示中文，卸载必须输入精确的数字 1。

**Architecture:** .NET Framework WinForms 两个入口共享代码，安装器等待全部 Photoshop 进程退出并稳定两秒后调用既有事务安装脚本。等待可取消，写入事务开始后禁止中途关闭。卸载 UI 与脚本双重校验确认值。脚本仍检查 PS 再次启动的竞态并回滚。保留独立插件身份；原源码、CCX 和构建流程不改动。

**Tech Stack:** Windows PowerShell 5.1、C#/.NET Framework、WinForms、System.Drawing、esbuild、Node test runner。

## Steps
1. 先添加卸载确认和中文错误测试，观察失败；扩展状态机测试覆盖运行/退出、取消、严格确认、重复启动。
2. 实现可测试的等待状态机、中文 WinForms 窗口、后台脚本执行与中文错误兜底。等待阶段不操作真实插件状态，不强杀 Photoshop。
3. 翻译脚本提示，记录底层技术错误到日志；源码与发布脚本均使用 UTF-8 BOM 兼容 PowerShell 5.1。脚本直接卸载也必须确认 1。
4. 安装图标使用现有蓝色 S；卸载图标采用蓝色 S 与橙红色减号的矢量设计，生成多尺寸 ICO 并嵌入 EXE。
5. 构建脚本编译两种入口并更新 ZIP，去掉发行包中容易混淆的 BAT。说明安装等待、取消、卸载与生效时间。
6. 执行原有安装回滚/隔离测试、新测试与界面预览，检查 ZIP/EXE 图标、原文件哈希；真实 PS 未关闭时仅验证等待与取消，不执行真实卸载。

已获用户确认：等待 PS 正常退出再安装、EXE 图标方案、中文提示、卸载输入 1。无需关闭或终止用户的 Photoshop。
