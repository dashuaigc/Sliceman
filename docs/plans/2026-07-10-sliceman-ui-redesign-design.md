# Sliceman UI 像素级改版设计

## 目标

在保持 Sliceman 现有 Photoshop UXP 插件功能和业务行为不变的前提下，将面板 UI 像素级还原为参考设计稿的深蓝色、卡片化、青色高亮风格。

像素对照基准为单个面板 `510 × 894 px`；面板缩小时保留纵向滚动和可用性。

## 范围与约束

- 保留完整切图、Symbols 切图、仅导出选中、包含隐藏图层、完整导出超出画布部分、批量前缀重命名等所有现有功能。
- 不修改 `src/lib/*` 和 `src/ps/*` 中的切图、命名、图层遍历和 Photoshop 操作逻辑。
- 保留现有关键 DOM ID 和事件流程。`panel.js` 只增加功能页切换、状态显示和必要的 UI 同步。
- 目标稿中新增但当前插件不具备的控件只还原外观，不扩展业务功能。
- 不依赖网络资源。所有 SVG 随插件一起打包。

## 实现路线

采用低风险的 HTML/CSS 重构方案：保留现有功能元素、ID 和业务调用，重组 HTML 层级并重写样式，仅用少量 JavaScript 管理三个功能页的切换。

不采用全量 JavaScript 组件渲染，避免增加 UXP 兼容性和事件重绑风险；也不采用简单的视觉覆盖，因为那无法准确还原三种页面状态。

## 界面架构

1. 顶部栏：Photoshop 图标、Sliceman 名称、版本标签、搜索、帮助和设置图标。
2. 项目名称卡片：三个功能页共用，继续使用现有持久化输入。
3. 功能中心：完整切图、Symbols 切图、批量前缀重命名、更多功能四张等宽卡片。
4. 功能内容区：根据选中卡片显示完整切图、Symbols 或重命名页面。
5. 底部栏：帮助和反馈建议入口，只还原视觉。

点击前三张功能卡仅切换 UI，不改变原有功能调用。“更多功能”、顶部图标和底部入口不绑定操作。

## 功能页

### 完整切图

- 保留包含隐藏图层、完整导出超出画布部分、只对选中图层/组切图三个选项。
- 三个原生复选框显示为滑动开关，底层仍使用原有 `checked` 状态。
- 导出设置显示“导出时选择”、固定选中的 PNG 和 1x。JPG、WebP 及其他倍率只展示弱化外观，不可操作。
- 主按钮调用现有完整切图或选中导出流程。

### Symbols 切图

- 显示 Symbols 切图说明。
- 保留三个现有选项和固定导出设置展示。
- 主按钮继续调用现有 Symbols 导出流程。

### 批量前缀重命名

- 保留前缀输入、实时预览和应用重命名。
- 预览显示为“原名称 → 新名称”，超出高度时在区域内滚动。

## 视觉规格

- 外框：深蓝黑背景、亮蓝描边、约 14 px 圆角和轻微外发光。
- 主背景约 `#06172B`，卡片背景约 `#0A1D32`，分隔线约 `#203950`，青色强调色约 `#08D7E8`。
- 文字：主文字使用近白色，说明文字使用蓝灰色，优先使用系统中文无衬线字体。
- 布局：左右内边距约 12–14 px，卡片间距约 8–12 px。
- 选中功能卡显示青色描边、内外发光和右上角勾选图标。
- 主按钮使用青色渐变。切图进行中切换为红色危险状态，继续显示停止提示。
- UXP 不支持的 CSS 效果使用稳定的渐变、边框和阴影降级实现。

## 资源

使用 `C:\Users\admin\Desktop\PS插件\sliceman_svg_icons` 中的 19 个 SVG，复制到项目的 UI 资源目录并通过构建脚本复制至 `dist/plugin`。运行时不访问桌面绝对路径。

## 状态、异常与确认流程

- 原有状态信息改为主按钮上方的临时提示，默认隐藏，运行、完成或报错时显示。
- ESC 暂停、终止任务、同名覆盖/跳过使用居中深色弹层。
- 弹层只更换布局和样式，继续解决原有 Promise，不改变暂停、恢复、覆盖和跳过语义。

## 验证与验收

### 自动验证

1. 运行现有 Vitest 测试，确保命名、遍历、Symbols 和重命名逻辑全部通过。
2. 构建 `dist/plugin`，确认 HTML、CSS、JS 和 19 个 SVG 资源均存在。

### Photoshop 手动回归

- 完整切图。
- Symbols 切图。
- 仅导出选中。
- 三个开关状态。
- 同名覆盖和跳过。
- ESC 暂停、恢复和终止。
- 批量前缀重命名和 Photoshop 撤销。

### 视觉验收

在 `510 × 894 px` 面板尺寸下与参考图逐项对照，重点验收外框、间距、卡片尺寸、SVG 图标、选中态、开关和主按钮位置。窄面板下验收纵向滚动、内容不重叠及所有现有操作仍可访问。
