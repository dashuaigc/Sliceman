# PS 切图插件 · 设计文档 (Spec)

- 日期: 2026-07-06
- 状态: 待评审
- 目标平台: Adobe Photoshop 2021+（UXP）

## 1. 概述

一个 Photoshop **UXP 插件**，用于把当前打开的 PSD 文档按图层/组自动切成独立图片。核心目标是 **零配置一键切图**：用户装好插件、打开 PSD、点一个按钮即可导出全部图层。

- 分发形式：打包为 `.ccx`，用户**双击**由 Creative Cloud 自动安装。
- 面板极简：项目名称输入框 + 「包含隐藏图层」勾选框 + 「开始切图」按钮 + 状态提示。
- 无需任何前置设置即可工作；颜色标记与项目名称为增强项。

## 2. 切图规则（核心逻辑）

对当前文档的图层树做**深度优先遍历（DFS）**。规则优先级：**红色 > 蓝色 > 默认**。

| 图层「颜色标记」 | 行为 |
|---|---|
| **默认**（无标记或黄/绿/紫/灰等其它色） | 每个**叶子图层**各自导出为一张独立图片；组本身不导出，仅作为命名路径前缀被遍历 |
| **红色**（图层或组） | 完全跳过、不导出。若为组，则整个子树都不导出 |
| **蓝色**（组） | 整组**合并为一张**图片导出，**不再深入组内**；组内被标记红色的图层在合并前先剔除 |

约定：

- 「颜色」特指 PS 图层面板中的**颜色标记 (label color)**，与图层内容颜色无关。
- 蓝色只对**组**生效；打在单个图层上按默认处理。
- 黄/绿/紫/灰等其它标记色**无特殊含义**，按默认导出。
- 文本图层、形状图层按普通图层栅格化后导出。
- 运行前必须有已打开的文档，否则面板给出提示并中止。

### 隐藏图层

- 「包含隐藏图层」勾选框，默认**关闭**。
- 关闭时：隐藏（眼睛关掉）的图层不导出，也不参与蓝色组的合并。
- 开启时：隐藏图层纳入导出与合并（导出时临时开启可见性）。

### 超出画布的部分

- 「完整切出超出画布的部分」勾选框，默认**开启**。
- 开启时（默认）：按图层完整的非透明像素裁切，**包含超出画布之外**的部分。
- 关闭时：先按当前**画布边界裁掉**图层超出画布的部分，再对画布内的可见像素做紧贴裁切；即导出内容不超过画布范围。
- 对蓝色合并组同样生效：关闭时先将合并结果裁到画布，再 trim。

### 遍历伪代码

```
function walk(node, pathPrefix):
    if node.label == RED: return            // 红色：跳过子树
    if node is Group and node.label == BLUE:
        exportMerged(node, pathPrefix + [node.name])   // 蓝组：整体合并，不递归
        return
    if node is Group:
        for child in node.children:
            walk(child, pathPrefix + [node.name])       // 普通组：作为前缀递归
        return
    // 叶子图层
    if node.hidden and not includeHidden: return
    exportLayer(node, pathPrefix + [node.name])
```

（蓝组合并时，先按 includeHidden 与红色剔除规则确定参与合并的可见图层集合。）

## 3. 命名规则

最终文件名结构：

```
[项目名称 _] PSD文件名 _ 组名(逐层) _ … _ 图层名
```

- 蓝色合并组以**组名**结尾，无叶子层段。
- 各段之间用下划线 `_` 拼接。

### 项目名称（可选输入）

- 面板提供「项目名称」输入框，可留空。
- 填写时：作为**最前缀**，用 `_` 与 PSD 文件名隔开。例：项目名 `shop` → `shop_shouye_daohang_tb`。
- 留空时：按 `PSD文件名 _ 组名 _ … _ 图层名`。
- 项目名称与其它段一样走规范化处理。
- **记住上次输入**：项目名称持久化保存，下次打开面板自动回填。

### 每段的规范化

按下列规则逐段处理：

1. **中文**：每个汉字取拼音**首字母**，使用内置离线拼音词典。多音字取词典**默认/常用读音**，不做上下文消歧。例「图标」→ `tb`。
2. **英文 / 数字**：原样保留。
3. 统一转**小写**。
4. **删除所有空格**；其它标点/符号一并删除，仅保留 `[a-z0-9]`。
5. 混合示例：「Icon图标 2」→ `icontb2`。

### 去重

- 若两段规范化后整体文件名相同（如「图标」「图块」都 → `tb`），第二个起自动追加后缀 `_2`、`_3`…，**绝不覆盖**已有文件。
- 去重范围：单次导出批次内按文件名全局判定；**同时**检查目标文件夹中已存在的同名文件（可能来自上一次导出），若已存在也继续追加后缀，确保不覆盖磁盘上任何既有文件。

### 兜底

- 某段规范化后为空字符串时，使用占位名（叶子层 `layer`、组 `group`）加序号，保证文件名合法且唯一。

## 4. 导出

- **格式**：PNG-24（保留透明通道，无损）。
- **裁切边界**：紧贴图层**非透明像素**的最小外接矩形（含已渲染的图层样式/投影/外发光）；蓝色合并组按合并结果的整体外接矩形裁切。是否包含超出画布的像素由「完整切出超出画布的部分」开关控制（见 §2）。
- **输出位置**：每次点击「开始切图」时**弹窗让用户选择目标文件夹**。
- **实现方式（推荐）**：通过 `batchPlay` 将目标图层/组复制到临时文档 → 执行 trim → 存为 PNG → 关闭临时文档。此法能保真图层样式与组内混合效果。
- **空图层处理**：若某图层完全透明、trim 后无像素，则跳过不导出，并在状态区计入「跳过」数量。

## 5. 批量前缀重命名工具

面板附带的一个辅助工具，用于**修改文档中实际图层名**（区别于导出命名，导出时仍会再做一次规范化拼接）。

- **作用对象**：当前在 PS 图层面板中**选中的图层或组**（可多选）。
- **组的处理**：选中组时**只改组本身的名字**，不递归修改组内子图层。
- **前缀输入**：面板提供前缀输入框。
- **前缀规范化**：前缀在写入前先做与命名相同的规范化（中文→拼音首字母、转小写、删空格与符号，仅留 `[a-z0-9]`）。
- **拼接方式**：规范化后的前缀**直接拼**到原图层名前面，不额外插入分隔符。例：前缀「图标」+ 图层 `home` → `tbhome`。
- **预览窗口（必需）**：点击「应用前缀」后，先弹出一个预览视图，列出所有选中项的 **原名 → 新名** 对照；用户确认后才真正写入图层名，可取消。
- **边界情况**：
  - 未选中任何图层 / 前缀规范化后为空 → 提示并中止，不做修改。
  - 预览中若两个图层将变成同名，不阻止（图层名允许重名），但在预览中标注提示。
  - 重命名只改名字，不影响颜色标记、可见性、图层内容。

## 7. 模块划分

按职责拆分为可独立理解与测试的单元：

1. **打包 / manifest**：UXP `manifest.json` + 面板 `index.html` / 入口 JS，产出 `.ccx`。
2. **图层遍历器 (traversal)**：读取图层树、判定颜色标记与可见性，按第 2 节规则产出「导出任务列表」（纯逻辑，可单测）。
   - 输入：图层树数据结构、includeHidden 开关。
   - 输出：`[{ type: 'layer'|'merged', nodeRef, pathSegments[] }]`。
3. **规范化器 (normalize)**：单段字符串规范化（拼音首字母 + 小写 + 仅留 `[a-z0-9]`），被命名器与前缀重命名工具共用。依赖内置离线拼音词典。
4. **命名器 (naming)**：基于规范化器做拼接 + 去重（纯逻辑，可单测）。
   - 输入：pathSegments 列表、项目名称、PSD 文件名。
   - 输出：唯一、合法的文件名字符串。
5. **导出器 (exporter)**：临时文档 + trim + PNG 存盘（对 PS API 的封装）。
6. **前缀重命名器 (renamer)**：读取当前选中图层/组 → 用规范化器处理前缀 → 生成 原名/新名 预览列表 → 确认后写回图层名（对 PS API 的封装）。
7. **UI 面板 (panel)**：切图区 + 前缀重命名区、输入框、勾选框、文件夹选择、预览弹窗、进度/状态、项目名称持久化（前缀不持久化）。

模块间通过明确的数据结构通信；遍历器、规范化器、命名器不依赖 PS API，便于脱离 PS 做单元测试。

## 8. 已确认的约定与假设

- 「颜色」= PS 图层面板的颜色标记 (label color)，非内容颜色。
- 黄/绿/紫/灰等其它标记色无特殊含义，按默认导出。
- 蓝色仅对组生效。
- 规范化仅保留 `[a-z0-9]`，其余字符（含标点、符号）删除。
- 文本/形状图层栅格化导出。
- 前缀重命名工具改的是**文档内真实图层名**，需在一次可撤销（undo）的历史步骤内完成，便于用户 Ctrl+Z 回退。
- 项目名称持久化存储于插件本地存储（如 UXP `localStorage` 或 secure storage）；重命名前缀为一次性，不持久化。

## 9. 测试要点

- **遍历器**：默认全切、红色跳过（图层与组）、蓝组合并且排除内部红色、普通组作前缀递归、多层嵌套、includeHidden 开/关。
- **命名器**：纯中文、纯英文、中英数字混合、含空格与符号、多音字取常用读音、重名加后缀、空段兜底、项目名前缀有/无。
- **导出器**：透明裁切正确、样式/阴影包含在边界内、蓝组合并保真、输出文件名与命名器一致、超出画布开关开/关两种边界正确。
- **前缀重命名器**：多选图层批量加前缀、选中组只改组名不动子层、前缀规范化（中文/含符号/空前缀）、预览对照正确、取消不改动、确认后名字写回、可撤销。
- **端到端**：一个含多级嵌套 + 红/蓝标记 + 中英文命名的样例 PSD，验证导出文件集合与预期一致。
