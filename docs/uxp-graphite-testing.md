# 石墨蓝 UI 测试版

## 加载到 Photoshop

1. 打开 Photoshop 27.11 和 Adobe UXP Developer Tools。
2. 在 UXP Developer Tools 中点 **Add Plugin**，选择 `D:\Sliceman\dist\uxp-dev\manifest.json`。
3. 对 **Sliceman Graphite Dev** 点 **Load**。面板名称为 **Sliceman · 石墨蓝测试**。
4. 如 Photoshop 提示需要启用开发者模式，按提示开启并重启 Photoshop，再 Load。
5. 后续修改后，在项目目录运行 `npm run build:dev`，然后在 UDT 中 **Reload**。

这是未打包的完整插件目录，不需要安装 CCX。独立 ID 为 `com.sliceman.plugin.graphite.dev`，与正式版 `com.sliceman.plugin` 不同，不覆盖已安装版。测试版的偏好设置和本地历史可能从默认值开始。开发构建没有浏览器示例数据。

建议先使用 360 × 780 左右的面板查看整体效果；最小宽度仍是 300px，内容多时可以纵向滚动。

## 本次改动

- v1.4.5：改尺寸合并为三步，新增 11 种规则示意，按需显示锚点，移除多尺寸入口。
- 输出与处理共用一页，摘要显示总数/已处理数，状态位于右侧；主操作按钮移除播放三角。

- 十个功能页、设置、查找、历史与预设、确认弹窗统一石墨灰背景与柔蓝强调色。
- 统一导航线性图标、顶栏设置、表单、开关、选中状态、主次操作按钮和提示浮层。
- 重命名显示实时选中数，原名与新名分列；长名称省略显示，“同名”与未匹配提示独立保留。
- 保留已有自绘按钮，避免 PS 27.11 原生按钮覆盖自定义颜色。
- 保留重命名模式与 `n` 编号规则；参考线分割直接生成图层，不再新建组（包含合并可见内容模式）。
- 选项及参考线按钮使用双层圆角填充修正底边；输入框左右留白 6px，切图与分割页间距收紧。

## Photoshop 内检查

1. 切换全部十个功能页；检查窄面板、纵向滚动、导航文字与按钮颜色。
2. 在重命名中切换替换/重新命名/前缀/后缀，打开编号，确认选中数、长名称及同名提示。
3. 打开设置、按名称查找、参考线历史、尺寸预设及确认弹窗；检查原生输入框和滚动条没有穿透弹层。
4. 检查输入框聚焦、Tab、Enter/空格按钮操作、禁用按钮、处理中停止按钮。
5. 在测试文档中执行改名、平移、排版、分割、表格、定位格、参考线和导出；验证各功能结果；参考线分割应生成独立图层而不新建组。

## 验证边界

README 的 17 张预览可通过 `scripts/capture-readme.cjs` 重新生成：先运行 `npm run build`，在仓库根目录启动 `python -m http.server 8765 --bind 127.0.0.1`，再用 Playwright 的 `browser_run_code_unsafe` 以该文件为 `filename` 执行。脚本运行真实面板构建，以浏览器宿主桩提供示例图层和文件；处理完成页使用展示状态，不执行实际导出。示例脚本不进入插件安装包。

Vitest 验证逻辑与面板接线；浏览器用于实际 HTML/CSS 在 300/340/420px 宽度下的布局检查。浏览器截图中的图层名称是示例数据，不能证明 Photoshop 原生渲染行为。最终颜色、输入框及浮层需以上述宿主检查为准。
