# Sliceman：智能对象内部批量粘贴 UDT 测试版

本版替换上一版“添加图层 / 应用样式 fx”的双模式功能。只有直接粘贴，不再获取样板，也不需要匹配名称或勾选样式。定位格的“对象间距”改动继续保留。

## 加载

1. 解压 `Sliceman_UDT_SmartPaste_HideExisting_20261110.zip`。
2. 如果 UDT 中还加载着旧的 `Sliceman Smart Content Test`，先 Unload 旧测试版。
3. 在 UXP Developer Tools 中 Add Plugin，选择本文件旁的 `manifest.json`，点击 Load。
4. 打开 `Sliceman · 批量粘贴测试` 面板，进入“批处理”。

测试版 ID 为 `com.sliceman.plugin.smartpaste.dev`，与正式版独立。清理旧版源代码不会自动移除 UDT 已加载的旧测试目录。

## 本次新增：隐藏原有图层

- 默认“否”，保留原有图层的显示状态；设置会记住上次选择。
- 选择“是”，粘贴并定位成功后隐藏内部原有图层和组；新增图层保留复制时的显示状态。隐藏组不会改动其子层原来的显示开关。
- 再次执行时，上一次添加的图层也属于“原有图层”。隐藏不等于删除，可手动重新显示。
- 原位：调用 Photoshop 原位粘贴，保持复制内容相对于画布的位置，不额外移动或缩放；与父文档里智能对象所在的位置无关。
- 居中：将所有新增图层的整体边界中心对齐内部画布中心，各图层之间的相对位置保持不变。

## 操作

1. 在 Photoshop 图层面板选中一个或多个完整图层，也可以选图层组。
2. 使用“编辑 → 复制”（Ctrl+C）。复制时退出文字编辑，不要选中矢量路径或像素区域；不要用“合并拷贝”。
3. 选中需要处理的多个智能对象图层，可以在另一个文档中选择。
4. 设置“最上方 / 最下方”和“居中 / 原位”，点击“粘贴到智能对象内部”。
5. 在插件面板底部查看处理进度及成功、跳过、失败计数；按钮下方不重复显示状态。有异常时点击“查看详情”。

批量执行期间请不要进行其他复制操作，整批使用 PS 当前剪贴板。插件不修改剪贴板，也不提供剪贴板历史或会话样板。

## 放置规则

- 默认最上方、居中；“居中”排在“原位”之前。已有保存的选择仍会恢复，手动切换后会记住。原位采用 PS 原位粘贴，保持原尺寸。
- 居中按本次新增图层的联合边界整体平移，保持彼此位置，不缩放。
- 图层顺序、原有组结构和自带蒙版、混合模式、透明度、fx 通过 PS 原生整层粘贴传递。插件不强制转成像素，也不额外套一层组。
- 最下方仍位于背景层及依附其上的剪贴链上方。
- 每次点击都新增一份，不替换或删除前一次内容。不要重复点击同一批来“刷新”。

## 支持范围

- 本测试版处理内部源为 PSD/PSB 的嵌入式智能对象。链接对象、JPEG/PNG/TIFF/AI/PDF 等原始文件来源会跳过，避免保存后无法保留图层。
- 内部文档已经打开时跳过，请先保存并关闭内部文档后再执行。
- 共享同一内部内容的智能对象在一批中只添加一次；同源的其他实例也会同步显示修改，包括未选中的同源实例。不会自动把它们转成独立对象。
- 只进入选中对象的第一层内部文档，不递归打开其中的智能对象。
- 剪贴板里若实际只有像素，PS 只能粘贴为像素图层；不会从合并后的像素恢复原有层结构。

## 保存与停止

- 每个对象成功后保存内部内容并关闭，原始父文档仍由用户决定何时保存。
- 单个对象失败时不保存该对象，继续其他目标；失败内容若无法关闭，会停止并显示处理办法。
- 执行时蓝色“粘贴到智能对象内部”按钮变为红色“停止”；点击后完成当前对象再停止，等待期间按钮不可重复点击。正常完成、停止或失败后，按钮恢复蓝色“粘贴到智能对象内部”。已完成对象保留结果，不承诺跨文档一次 Ctrl+Z 全部撤销。
- 结束后回到原文档并恢复最初选择。保存成功但关闭异常会单独提示。

## 建议测试顺序

先在文档副本中测试，使用可直接在 PS 手动进入并粘贴的 PSD/PSB 智能对象。

| 场景 | 预期 |
| --- | --- |
| 隐藏原有图层为“否”（默认） | 原有可见层和隐藏层的状态均保持 |
| 隐藏原有图层为“是” | 原有图层/组隐藏，新增内容保留复制时的显示状态 |
| 隐藏为“是”，粘贴或定位失败 | 当前对象不保存半成品 |
| 复制一个带 fx 的图层，选两个独立对象 | 两个内部都新增一层，fx 随层保留 |
| 复制高光、纹理、调色多个图层 | 各层独立，顺序、相对位置及属性与手动粘贴相符 |
| 复制含蒙版、嵌套组及剪贴链的完整组 | 结构保留，不新增外包装组 |
| 原位，目标画布大小不同 | 与 PS 原位粘贴结果一致，不自动缩放 |
| 居中，目标画布大小不同 | 整批图层联合边界居中，不逐层单独居中 |
| 最下方，内部有背景层和剪贴层 | 添加在背景剪贴链上方，原有剪贴关系保留 |
| 内部最后活动层在已有组中 | 新增内容放到根部指定层级，原有组内容保留 |
| 多选同源实例 | 内部只新增一份，同源实例同步 |
| 普通层、链接对象或 JPEG 来源混选 | 不处理这些项，详情写明原因 |
| 未复制、复制了不可粘贴内容 | 提示重新复制，目标不保存半成品 |
| 内部文档已打开且有修改 | 跳过，不保存或关闭用户已打开的内容 |
| 再执行一次 | 追加第二份，原有内容完整保留 |
| 执行过程中点击停止 | 完成当前对象后停止，返回原文档 |

## 验证记录

本次验证：智能对象服务、面板交互和 UI 标识相关测试通过；开发构建与 UDT 测试包已检查。

自动化测试覆盖原生 API 的调用边界、层序、位置、结果统计、共享去重、失败和取消处理；浏览器宿主桩用于面板交互与窄宽度布局检查。

这些检查不等于 Photoshop 真机剪贴板验证。多层原生粘贴、不同颜色配置、实际 PSB 保存，以及不同 PS 版本的行为，需要在 UDT 加载后按上表实测。
