## 安装

两种安装格式功能相同，任选一种即可：

| 安装方式 | 下载文件 | 使用方法 |
| :--- | :--- | :--- |
| Creative Cloud 版（Windows / macOS） | **Sliceman_v1.4.7.ccx** | 双击，通过 Creative Cloud 安装后重启 Photoshop |
| 本地一键安装版（Windows） | **Sliceman_Setup_v1.4.7.zip** | 完整解压，双击“一键安装.exe”；若 PS 正在运行，保存并退出后自动继续 |

**旧版首次升级**：已安装的 v1.4.6 及以前一键安装版仍带有旧下载逻辑，请在本页 Assets 中手动下载 Setup ZIP 安装 v1.4.7。此次升级后，后续更新会自动选对格式。CCX 不会升级本地版；请勿在 ZIP 内直接运行 EXE。Photoshop 最低要求为 23.3。
