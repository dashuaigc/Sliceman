## 更新内容

- 定位格新增“对象间距”输入框：填写后，定位格之间的横向、纵向间隔统一使用该值；留空沿用原有自动间距，支持 0 px。
- 批处理新增“批量向智能对象内部添加图层”：先在 Photoshop 复制单个或多个完整图层/组，再选择目标智能对象，一次添加到多个对象内部。
- 支持最上方/最下方、原位/整体居中；通过原生整层粘贴保留图层结构及自带效果，每次执行追加一份。
- 主按钮运行时切换为红色“停止”，完成、停止或失败后恢复蓝色“粘贴到智能对象内部”；进度与结果只显示在面板底部。
- 更新 README 与 GitHub Pages 的操作说明，刷新 20 张功能界面及状态预览，保持原有手册和截图格式。截图为当前 HTML/CSS 浏览器渲染，使用示例数据，非 Photoshop 实机截图。

## 安装

两种安装格式功能相同，任选一种即可：

| 安装方式 | 下载文件 | 使用方法 |
| :--- | :--- | :--- |
| Creative Cloud 版（Windows / macOS） | **Sliceman_v1.4.6.ccx** | 双击，通过 Creative Cloud 安装后重启 Photoshop |
| 本地一键安装版（Windows） | **Sliceman_Setup_v1.4.6.zip** | 完整解压，双击“一键安装.exe”；若 PS 正在运行，保存并退出后自动继续 |

一键安装包包含安装、卸载 EXE 及全部配套文件；请不要在压缩包内直接运行或只移动 EXE。更新时请选择与原安装方式一致的格式，CCX 不会升级本地版。Photoshop 最低要求为 23.3。
