## 更新内容

- 改尺寸改为三步流程：选择图片 → 尺寸设置 → 输出与处理。
- 尺寸规则名称更直观：指定宽高、按宽度缩放、按高度缩放等，共八种规则。
- 新增 11 种规则示意图，随规则和适应方式自动切换；只有需要裁切或补边时显示锚点。
- 调整预设管理、保存预设和空白区域填充的位置，统一步骤间距，加大加粗步骤文字。
- 输出设置与处理进度合并，收紧间距；状态放到摘要右侧，计数采用「共 总数/已处理数 张图片」。
- 移除多尺寸输出入口，每张源图片生成一张结果；旧版多尺寸配置不再触发额外输出。
- 移除主操作按钮上的白色播放三角，保留文字。
- 重新生成全部 17 张功能页及弹窗预览，更新 README 使用说明。截图为当前 HTML/CSS 的浏览器预览，使用示例数据，非 Photoshop 实机截图。

## 安装

下载 **Sliceman_v1.4.5.ccx**，双击安装后重启 Photoshop。
ZIP 为同内容备份；开发者可解压后通过 UXP Developer Tool 加载根目录的 manifest.json。
