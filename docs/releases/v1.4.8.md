## 更新内容

- 批量向智能对象内部添加图层新增“隐藏原有图层：否 / 是”，默认否。选择是后，粘贴和定位成功才隐藏内部原有图层及组，新增图层保留复制时的显示状态。
- 隐藏组保留其子层的显示开关；原有内容不会删除，可重新显示。再次执行时，上次添加的图层也属于原有图层。
- 放置位置默认改为“居中”，选项顺序改为“居中 / 原位”。多个新增图层作为整体对齐内部画布中心，保持尺寸和彼此位置。
- 选项会记住上次选择；升级前已保存“原位”的用户，手动切换一次“居中”即可保存。
- 更新 README 与 GitHub Pages 的说明和界面截图，保持原有手册格式。截图使用浏览器宿主模拟数据，非 Photoshop 实机截图。

## 安装

两种安装格式功能相同，任选一种即可：

| 安装方式 | 下载文件 | 使用方法 |
| :--- | :--- | :--- |
| Creative Cloud 版（Windows / macOS） | **Sliceman_v1.4.8.ccx** | 双击，通过 Creative Cloud 安装后重启 Photoshop |
| 本地一键安装版（Windows） | **Sliceman_Setup_v1.4.8.zip** | 完整解压，双击“一键安装.exe”；若 PS 正在运行，保存并退出后自动继续 |

v1.4.7 起，插件检查更新会选择当前安装方式对应的包。v1.4.6 及以前的一键安装版，请手动在 Assets 中选择 Setup ZIP；CCX 不会升级本地版。请勿在 ZIP 内直接运行 EXE。Photoshop 最低要求为 23.3。
